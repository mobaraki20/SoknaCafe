SOKNA Windows Platform Preview 0.1.0 — unsigned test build

This package adds Windows platform maintenance to an ALREADY CONFIGURED SOKNA
application. It is not the complete clean-machine SOKNA installer.

Required before installation: configured application (config.php/install.lock),
PHP 8.2+ with required extensions, OpenSSL, database and web server.
Application/data paths must be outside the platform installation directory.

Repair restores platform files and shortcuts and delegates Runtime/TLS repair
to the existing setup owner. It never restores a database or overwrites the
active application with an older release. Same-version application-file repair,
automatic prerequisites and HTTP/database health are still pending.

Use Modify in Programs and Features, or SOKNA Platform Repair in Start.
Uninstall verifies ownership before removing the Runtime and internal Print Worker
services, platform files and shortcuts. Application files, print queue/configuration,
data, keys, TLS trust/mapping and external legacy Print Agent are preserved.
Existing application files must not be deleted while they are still needed.

Setup writes an Inno log automatically. The final result displays the separate
owner diagnostics directory and support.zip. The sanitized bundle includes a
snapshot of the installer log through setup-owner completion, plus component
diagnostics. Later installer finalization is not in that snapshot. Do not include
credentials on installer command lines.

Built with Inno Setup: https://jrsoftware.org/
No paid license, subscription or certificate is required for this test build.
