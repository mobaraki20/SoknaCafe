# هنداور توسعه Sokna 1.36.1

## وضعیت انتشار

- نسخه مقصد: `1.36.1`
- Baselineهای رسمی Update: Full Projectهای منتشرشده `1.36.0` و `1.36.1-rc.1`
- Updater Engine: `1.5.3`
- Migration دیتابیس: ندارد
- نوع تحویل: Full Project + Update استاندارد + SHA256SUMS
- استقرار Production: انجام نشده

## دامنه نسخه نهایی

نسخه نهایی تمام اصلاحات `1.36.1-rc.1` را حفظ می‌کند و اصلاحات زیر را نیز اضافه می‌کند:

- فهرست انتظار خرید Mobile به List متراکم با Divider و Actionهای غیرتمام‌عرض تبدیل شد.
- ردیف Quick Order دارای تعداد و بیرون‌بر، اطلاعات قلم را تمام‌عرض و کنترل‌ها را در ردیف جدا نمایش می‌دهد.
- شیت سه‌نقطه با `CafeUI.bindSwipeDismiss` بسته می‌شود.
- تغییر Label اعلان فقط متن داخلی را عوض می‌کند و SVG را حذف نمی‌کند.
- Notification فراخوان گارسون با «رسیدگی شد» فراخوان را در Transaction تکمیل، Guard میز را آزاد و Audit ثبت می‌کند.

## قراردادهای حفظ‌شده

- State machine چاپ، Print API v4 و Agent در این Release تغییر نکرده‌اند.
- Schema و Migration دیتابیس تغییر نکرده‌اند.
- Workflow خرید، API و ساختار Desktop خارج از اصلاحات اعلام‌شده تغییر نکرده‌اند.
- شناسه فنی Action اعلان برای سازگاری Service Workerهای نصب‌شده حفظ شده است.

## آزمون و UAT

نتیجه و محدودیت‌های آزمون در `docs/TEST_REPORT_V1.36.1_FINAL_FA.md` ثبت شده‌اند. UAT واقعی Updater، PHP/DB، مرورگر، گوشی، Service Worker و چاپگر باید روی Clone یا محیط مرجع اجرا شود.
