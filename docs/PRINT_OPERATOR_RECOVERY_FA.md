# راهنمای اپراتور چاپ — Sokna 1.36.4-dev.16

- **در انتظار:** Print Intent ثبت شده و هنوز در اختیار Agent نیست.
- **رزرو/پذیرفته:** Agent در حال تثبیت مالکیت است.
- **تحویل به ویندوز:** Spooler Job را پذیرفته؛ این به معنی خروج قطعی کاغذ نیست.
- **نامشخص / نیازمند تعیین تکلیف:** احتمال ارسال وجود دارد و سیستم چاپ خودکار مجدد انجام نمی‌دهد.
- **خطای امن پیش از ارسال:** retry محدود/دستی می‌تواند مجاز باشد.

برای `unknown` یا `recovery_hold` قبل از چاپ مجدد، کاغذ و Windows Queue را بررسی و نتیجه انسانی را ثبت کنید. Retry دستی روی `failed` یک چرخه تازه می‌سازد و تاریخچه قبلی حذف نمی‌شود.

Local Wake فقط سرعت دریافت را بالا می‌برد. اگر permission مرورگر یا Bridge در دسترس نباشد، Poll پایدار Agent کار را پیدا می‌کند.
