# Polish رابط تسویه آیتمی — 1.36.4-dev.4

## هدف
این مرحله فقط خوانایی و بهره‌وری فضای رابط صندوق را بهبود می‌دهد و هیچ قاعده مالی، Allocation، Inventory، COGS یا Lock عملیاتی را تغییر نمی‌دهد.

## تغییرات
- کارت‌های انتخاب قلم فشرده‌تر شدند، با حفظ Touch Target حداقل 44px.
- خلاصه «جمع حساب / پرداخت‌شده / مانده» در موبایل در یک ردیف فشرده باقی می‌ماند.
- «انتخاب همه مانده» در Header انتخاب و بدون اشغال یک ردیف کامل نگه داشته شد.
- تعداد واحدهای انتخاب‌شده و مبلغ انتخاب در پایین لیست هم‌زمان نمایش داده می‌شوند.
- قلم انتخاب‌شده با Border/Background ظریف مشخص می‌شود.
- Footer پرداخت جداگانه دیگر روی آخرین اقلام لیست قرار نمی‌گیرد.
- متن‌های توضیحی سیستم حذف/کوتاه شدند و فقط وضعیت کوتاه «تسویه جداگانه فعال» نمایش داده می‌شود.
- CTA بعد از پرداخت جزئی به «پرداخت مانده … تومان» تبدیل شد.
- «افزودن قلم جاافتاده» Secondary Action تمام‌عرض است.

## قرارداد حفظ رفتار
- Settlement و API payloadها بدون تغییر معنایی هستند.
- رسیدهای قبلی، تخفیف، Allocation و Signature همان قواعد dev.3 را دارند.
- Quick Order معمولی بعد از شروع تسویه جزئی همچنان قفل است.
- مسیر «افزودن قلم جاافتاده» همان قاعده dev.3 را حفظ می‌کند.
