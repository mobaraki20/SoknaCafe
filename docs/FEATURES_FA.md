# قابلیت‌های جاری Sokna 1.36.0

- منوی مهمان و سفارش میز
- کار روزانه، Quick Order و انتقال میز
- صف آماده‌سازی آشپزخانه/بار
- تسویه مستقیم، مشترک و اقامتگاه
- فاکتور، دوره مالی و اسناد برگشتی
- مشترکین و گردش حساب
- میزها، QR و مدیریت دسترسی QR
- روز عملیاتی، شیفت و گزارش عملیات
- تحلیل مدیریت
- انبار اختیاری با Ledger/Recipe/شمارش؛ خاموشی آن سفارش، صندوق و چاپ را متوقف نمی‌کند
- خرید و تأمین اختیاری و وابسته به انبار؛ انبار می‌تواند بدون خرید فعال بماند
- مدیریت قابلیت‌ها برای Inventory، Supply، Marketing، Reporting و Personnel
- رویداد، کمپین و تنظیمات منو
- اعلان Push با Outbox/Worker
- Backup، Restore و Update/Recovery Center
- Help Center داخلی

## چاپ
سرور Sokna Queue و Mapping چاپ را نگه می‌دارد، اما Agent Windows در این Release **خارج از Scope پذیرش Production** است و باید جداگانه تست و تأیید شود.
