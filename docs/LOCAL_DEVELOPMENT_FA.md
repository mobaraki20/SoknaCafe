# محیط توسعه محلی

## روش Docker

در صورت نصب Docker:

```bash
make up
```

سپس `http://localhost:8080/install.php` را باز کنید و اطلاعات زیر را وارد کنید:

- میزبان دیتابیس: `db`
- پورت: `3306`
- نام دیتابیس: `cafe_qr`
- کاربر: `cafe`
- رمز: `cafe_dev_password`
- آدرس نصب: `http://localhost:8080`

خاموش‌کردن:

```bash
make down
```

نمایش Log:

```bash
make logs
```

## نکته

اطلاعات Docker فقط برای توسعه محلی است و نباید با همین رمزها در سرور واقعی استفاده شود. فایل `config.php` تولیدشده محلی را در بسته انتشار یا Git قرار ندهید.
